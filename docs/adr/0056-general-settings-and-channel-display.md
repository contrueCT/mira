# ADR 0056：通用设置与外部渠道消息显示

状态：已批准，已实现。

设置第一项为「通用」，包含消息显示及原「访问」页的网页密码设置。移除独立访问页；模型设置仍有独立页签。

「显示其他渠道的消息」默认关闭，只筛选带有可信扩展来源的入站和出站消息。Mira 普通回复、网页消息与系统通知继续显示。过滤不修改事件、Wake、模型上下文、持久历史或原有引用快照；引用跳转到隐藏消息时沿用不可见目标提示。

配置保存在 MIRA_HOME/general.json，所有设备共用；重启与记忆重置后保留。GET/PUT /api/settings/general 使用现有鉴权及 Host/Origin 防护；PUT 接收 revision 和 showExternalMessages，串行写入并核对 revision，冲突返回 409，原子替换配置文件。

Timeline 在同一次读取中冻结显示设置，过滤发生在可见条数计数前，继续使用原始历史游标和有界扫描。各 Timeline 响应携带 displayRevision；浏览器观察到新版本时重建当前消息窗口与分页状态，保留输入草稿、附件和待确认发送。旧版本响应不得把隐藏消息重新合入；其他设备在下一次轮询时同步。

验证包含配置文件重读/损坏/冲突、真实 PostgreSQL 分页与引用隐藏、真实浏览器跨设备同步、通用页顺序与窄屏布局。测试使用合成模型，不调用真实飞书或付费模型。
