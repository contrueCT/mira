# ADR 0045：允许工具结果目录的可写祖先目录

状态：Accepted，2026-10-17。用户明确要求移除“父目录允许其他用户写入就拒绝”的限制。

## 决定

`writeWakeInput` 不再根据路径祖先的组/其他用户写权限或 sticky bit 组合拒绝写入。已有父目录权限保持原样，实际文件访问由宿主 OS 权限决定。适用于超限 Wake 输入、工具大输出和共用此存储的终端结果。

managed data root、spool 根、发布目录和文件的私有权限及所有者要求保留；祖先目录所有者检查保持原有规则。符号链接、非目录组件、源码/数据路径分离、稳定键内容冲突、文件身份复查与原子不可覆盖发布不变。不清空上下文、不删除或重跑已保存的工具结果。

允许可写祖先目录后，此实现不承诺防御其他 OS 用户并发替换这些祖先目录。该选择由用户明确确认；不添加替代 chmod、配置开关或第二套拒绝条件。

## 验证

回归使用 `777` 非 sticky 祖先，验证完整大输出写入、普通文件读取、同键复用、冲突保留和缺失重建，并确认父目录权限不变、结果文件仍私有。运行时回归穿过真实工具结果持久化、文件投影和普通 read 工具，验证模型能读取完整结果文件及恢复时不重复执行工具；模型响应为合成，不能替代真实供应商验证。
