# ADR 0044：关闭单次运行错误提示

状态：Accepted，2026-10-17 用户批准。

服务端每次记录运行错误生成独立 UUID `errorId`，同一次错误随状态轮询保持稳定。开始下一次处理时清除错误及 ID；另一轮失败即使文字相同也获得新 ID。保存模型配置不伪装成运行恢复，不自动重试失败请求。

浏览器的关闭按钮只隐藏对应 ID 的横幅，以 sessionStorage 保存最后关闭的 ID，刷新后仍有效；存储不可用时退化为本次挂载内有效。顶部异常状态保留，并提供查看错误入口。新的 ID 重新显示。错误文本和凭据不写浏览器存储。连接和消息存储故障独立保持可见。

不新增数据库记录、后台确认接口或重试动作。服务重启后的新错误获得新 UUID。

验证包含真实 PostgreSQL/service 的错误 ID 生命周期、HTTP 状态投影、浏览器轮询/刷新/重复错误/重新展开以及窄屏截图。
