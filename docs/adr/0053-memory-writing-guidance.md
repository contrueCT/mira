# ADR 0053：记忆写入引导（系统提示 v0.6）

状态：Accepted，2026-11-01。用户决定：关于“不要记什么”写轻一些；强调只要有想记的内容就可以记，不必很大或很重要，记忆是感知、理解世界的一部分；扮演角色时按角色会在意、会记下的事情来记；给出示例。

## 决定

- 系统提示 v0.6（`mira-system-v0.6.md`，section 仍为 `mira.system.v0.2`）只替换 `<memory>` 一节和版本标题，其余字节与 v0.5 相同。
- 新的 `<memory>`：保留 `{{MEMORY_ROOT}}`、`MEMORY.md` 进入基础上下文、记忆与 Life History 的区别；去掉 “When useful” 与 “Only when … genuinely long-term … consider” 的高门槛和“情绪不必写进 Memory”；改为觉得值得留下就在同一个 wake 里安静地记下；扮演角色时按角色视角记；“不要记什么”合成一句（不记流水账，不留无意义的时间戳/ID）；六条示例。
- 其他小节里的 “semantic memory” 等措辞不变。
- v0.5 字节保留为历史模板，旧快照照常校验；v0.4 及更早同样不变。

## 已知限制

- 原生模型在 v0.6 下的记忆写入行为尚未录制验证（未运行付费探针）；回放证据早于此次修改。
- 不改变 Dreaming、压缩或工具；写入仍由模型用普通文件工具完成。
