# 指定消息回复与时间线验收

## 范围

对应 [ADR 0043](../adr/0043-message-replies-timeline.md)。保留单条浅色聊天界面，新增稀疏时间分隔、气泡外时间/来源、用户引用 Mira 与 Mira 显式引用用户。引用是服务端验证的 History 身份和有界原文快照，不是第三方发送许可。

## 测试入口

- `pnpm check`：严格类型、包边界、离线/组件测试和生产构建
- `pnpm test:integration`：真实 PostgreSQL 的输入、来源隔离、双向工具发布、恢复/重试与压缩回归
- `pnpm test:e2e`：既有合成 UI fixture，包括键盘/触屏、取消、分页查找、未知引用兜底
- `pnpm test:replies:e2e`：真实 Chromium → HTTP → PostgreSQL → Wake/runtime → `send_reply`，只有 provider 响应为确定性合成

新真实浏览器套件使用自然的合成出游对话及通用测试来源，覆盖正文和图片引用、取消/换目标、精确 canonical ID、唯一工具发布、丢失 HTTP 回执后的核对、重复/冲突、来源快照、重启及桌面/窄屏布局。它没有使用用户提供的私人聊天截图或真实账户信息。

截图由上述套件写入 `test-results/replies-real/`，作为 CI artifact 保留而不提交源码。用户实际配置模型是否自然选择正确的回复对象与正文属于额外 live 质量验收，本套件不声称已验证。

## Native 模型行为补充验收

[行为记录与复现边界](reply-native-behavior.md) 保留六个冷启动 native 模型的全部首次选择（13 条决策），覆盖旧引用、相似消息中选择原话、工具期间插话、压缩索引与历史查询、旧未标记输入和恶意引用。模型只收到真实 runtime 请求与通用响应格式，没有获知预期目标或应调用的工具。离线实际工具执行已完成，属于 native 模型行为模拟，不代表用户实际配置模型的 live API 质量。

`recovery/reply-native-behavior.test.mts` 将原始选择回放到真实 PostgreSQL/Web/runtime，逐次核对完整生产工具 schema、唯一来源身份映射及真实结果；`test:replies:e2e` 另含两项 native 选择的实际页面验收。回放不生成新模型判断，也不得改写原来选中的消息、工具顺序或正文。这些新增真实回放门禁仍须在最终精确提交 CI 通过后才计完成。
