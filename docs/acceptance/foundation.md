# 分阶段验收

所有条目都是验收目标，不是已完成清单。每次提交在结果文档记录实际执行情况。

## F0 基础结构

- 原始设计按原始字节保存，可校验 SHA-256
- 已确认的包目录、职责、数据隔离和待决策清单齐备
- 工具链确认后，可从锁文件全新安装、类型检查、测试、构建
- 公开 exports 和依赖边界检查能拒绝违规导入，并有反例测试
- CI 在具体提交上通过；未实现功能明确标识
- 新的独立审查完成，修复后另起审查

## F1 Pi 可行性（主循环前置门槛）

- 固定并记录实际验证过的 Pi 包版本与上游来源
- 原始结构化消息序列化/恢复，含文本、工具调用/结果与供应商必要字段
- 一次 Wake 后重启，再继续时保留最近原始上下文和指代
- 工具调用执行前后均能增量记录；多工具及中断不导致重复副作用
- 验证 Pi 回调是否真正 await，以及哪份消息状态是恢复权威
- 使用真实压缩机制验证 summary + recent tail，工具调用/结果不被拆坏
- 压缩后继续、压缩中断、上下文版本冲突均有断言
- 无模型凭据时只报告离线可验证结果；真实模型部分保持未执行
- 实验结果说明限制并支持 Runtime 选型确认，不把演示当生产实现

## F2 持久化与单主循环

- 事件与 Wake 区分、去重、合并、排队，未请求唤醒的事件不启动推理
- 跨进程单写者与上下文版本检查，测试锁失效和旧进程继续运行
- 增量工具记录、outbox、幂等键，覆盖提交前/后崩溃窗口
- 结果不明的外部执行不会自动重放，能恢复为待核对状态
- 连续两次 Wake 与进程重启仍对应同一个 Mira，原始历史不丢失
- 时间提示根据事实渲染，不产生多余 TimePassed 领域事件

## F3 工作空间、授权与 Timeline

- Memory 位于源码仓库外并进入独立 Git；无独立 SemanticState，快照与 lineage 可恢复
- 按 ADR 0006，普通文件修改不默认通知、不 Wake、不重注入；真正初始上下文才加载 MEMORY.md，普通恢复保留持久快照
- History 查询与原始记忆分开，Memory 文件不被强制塞入 provenance
- 授权证据绑定具体工具/范围/有效条件，第三方内容无法授权
- Timeline 不展示内部 Runtime Trace 为人生事件，没有 New Chat
- Compaction 不修改 Memory，Dreaming 不替代上下文管理

## 完整 Mira Prompt 与 v0.5 增量

- v0.5 与 Prompt 设计 v0.1、实际模板 v0.2 原始字节/hash 匹配，v0.4 存档不变
- 无 Memory 时、初始流和已有流的实际 provider 请求均收到完整身份、行为与 13 个示例
- 一个有效具名 Prompt，动态时间/能力来自实际请求边界，普通工具批次后的新能力说明与执行注册表一致
- 白名单单次替换、动态文本转义、未知/缺少占位符、Unicode 和对抗性标签均有测试
- 具名更新/迁移走追加历史及 fenced writer/CAS；重启/崩溃恢复幂等，旧历史和工具声明保留
- Memory 编辑不 Wake、不增加模型调用、普通恢复不重读；旧 State 字节不变且无自动转移
- 压缩保留有效 system，空终止输出可完成静默 Wake；不捏造真实模型质量结果
