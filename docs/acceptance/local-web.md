# 本地 Web 验收

本文件列出本批验收范围，实际通过数量以确切提交的 CI 输出为准；未通过的项目不能称为完成。

- Fastify Host/Origin/请求头、方法、JSON/大小、来源与错误净化；静态资源范围、符号链接与 malformed URL
- 模型设置格式、引用而非密钥、原子保存、revision 冲突、外部编辑与链接路径保护
- 同一 Mira 消息落库、重复提交去重、刷新/重启恢复、取消后同一 Wake 继续、无配置不调用模型
- UI 不输出 system/thinking/raw tool records，普通用户消息与外部来源区分
- 桌面和 390px 窄屏截图、输入栏、重复 Enter、完整回复、刷新
- 设置关闭/Escape/返回/前进、网络错误、不确定提交跨刷新不自动重发
- 历史时间游标、相同时间稳定排序、异常时间仍可分页、原始记录不改写

开发环境可运行 HTTP，但 PostgreSQL/Chromium 所需 Unix socket 被拒绝；未绕过。真实 PostgreSQL 与浏览器验收由私有仓库 CI 执行，截图必须下载并实际检查后才能完成视觉验收。

真实模型请求、用户凭据、人格/自然语言授权判断质量、公网部署、账户与移动端原生应用不在本批验收中。
