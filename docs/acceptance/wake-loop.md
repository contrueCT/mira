# 合并唤醒与单认知循环验收

日期：2026-10-05。设计和批准范围见 [ADR 0002](../adr/0002-coalesced-wake-loop.md)。

## 本地已验证

固定 Node 24.19.0、pnpm 11.28.4、TypeScript 6.0.3、Pi 1.0.2。`pnpm check` 包括严格源码类型检查、依赖边界、92 项离线测试及检查工具构建，通过，0 失败、0 跳过。Pi 声明兼容例外仅覆盖 Pi 消费项目，核心仍检查声明文件。

- Event-only 不调用模型，多条 Wake 合并为一轮，运行中到达的请求下一批处理
- 同一 writer 不允许并发 drain，所有权失效/取消停止后续步骤
- Pi 输入及终止回复与 Wake 关联；提交后响应丢失、错误响应后继续、最终回复链接损坏均有断言
- 未知/尚未开始的操作持久化为真实说明；保留原始调用、已知结果及其它叙述
- 未知后仍可查询和产生新调用；相同参数作为判断事实，不固定阻拦，授权证据保留自然语言理由
- 判断应先询问用户时，保存未开始及原因并继续认知，不需要批准 UI
- 全 SDK 压缩后未决事实可重新呈现，不以生成摘要代替执行证据
- 超限完整批次为普通 `batch.txt`，路径通知不声称已读；普通文件工具读取
- 文件重建、真实子进程重启、并发发布、冲突保留、遍历/符号链接/硬链接及不自动删除未读文件
- CLI help 无需数据库或模型凭据

## 真实 PostgreSQL 验证

已添加实际数据库测试，覆盖原子 claim/input/final/complete、幂等/冲突、迁移回滚、锁丢失、真实进程退出与 SIGKILL、模型/工具悬停时的新进程接管、同一 Mira 重启、普通文件工具和假 provider 组装。

本地环境禁止 PostgreSQL Unix socket，未改开 TCP，也未执行本地驱动/多进程数据库测试。真实数据库验收使用仓库现有 GitHub Actions 官方 PostgreSQL 18.6 服务，`pnpm check:all` 必须通过后才能报告数据库通过。

CI 及独立审查结果会在验证完成后补充；当前不能把新增测试或离线通过当作真实数据库通过。

## 保留限制

- 无真实模型/provider 联通、摘要语义质量或真实远端副作用验证
- 不提供外部 exactly-once，不自动重放未知操作；原始调用 ID 不能复用
- 通用自然语言授权解释、HTTP/UI、定时调度、Memory/State、扩展及自动压缩触发策略仍未实现
- 普通 Pi 文件读取遵循其已有输出限制；未引入特殊分段工具，也未新增 shell 权限
- 内联字节上限不等于完整模型 token 预算，事件历史和工具原文仍保存在权威存储
