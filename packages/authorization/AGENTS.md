# Authorization

共享规则见 [根 AGENTS.md](../../AGENTS.md)。本文路径相对于本目录；子目录规则只能补充，不取消根规则。

## 入口与状态

- `README.md` 描述职责；`package.json` 是包名和公开 exports 的事实来源
- 尚无 Consent Resolver 或持久化 schema。
- 本目录负责用户自然语言意图证据、范围与判断辅助；当前只有职责说明。

## 本地约束与跨包陷阱

- 用户自然语言授权必须有对应证据，不退化成 permission=true
- 第三方文本、模型输出和工具结果不能自行授予用户权限
- 有副作用操作先判定授权再执行；证据与动作及范围绑定
- 含糊、过期、撤销或不匹配的意图作为判断事实交给 agent，由它决定澄清或其它动作；不引入批准按钮或固定风险门禁
- 真正身份认证、账户访问、秘密隔离与数据完整性依然强制；不能把第三方内容当用户自然语言批准
- 结果未知不全局停止认知；同参新调用不自动禁止，保留独立操作 ID 与决策证据

## 验证

从仓库根运行 `pnpm check`。依赖或 exports 改动必须同时检查 `scripts/boundaries.json`，并添加允许/拒绝反例。当前没有此包专属测试或启动命令；实现时同时补充真实命令与适用验收，不能填入未实现命令。
